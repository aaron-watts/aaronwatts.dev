NextCloud

20th April, 2026

NextCloud is a cloud storage solution that is intended as privacy focused with an option for self hosting. I've been using it for a while now, and I am very happy with it.

NextCloud is an alternative to things like Google Drive and One Drive that doesn't hand your data and the control over to a conglomerate. Self hosting is not the simplest thing to do, but there are also providers available that do all the hard stuff for you so you can just get on with having a cloud.

Originally, I was subscribed to Murena's Workspace cloud plan. I didn't have a Murena phone, but the NextCloud offer looked quite good so I tried it. I was pleased, the WorkSpace is pretty good, and includes an OnlyOffice suite for online editing. A measly €1.99 per month gets you 20GB of storage, or you can get 64GB for just €3.99. However, they had some issues a while back when upgrading their infrastructure, and their cloud went down. It's back up now, and due to the way NextCloud syncs with devices, I had local backups on several devices so I didn't lose any files.

But the downtime was a bit longer than anticipated, and during that time I thought I might try set up my own cloud on a VPS. And I did, successfully. I pay a lot more for my NextCloud on a VPS setup, but I get total control of what apps I have on my server. That said, I also have total responsibility when things stop working, which has happened.

Installation is not simple, there are All-In-One installations which are supposed to make things easier, available as either a Snap package or a Docker image, but for me (a novice) the documentation didn't seem to match up and I couldn't get everything working.

If you have some experience in the Linux terminal, then I highly suggest following along to the Learn Linux guide, which is also available as a YouTube walthrough (linked in article). Jay does a great job of explaining what he is doing and why, and if you've ever poked around in PHP applications it should feel quite familiar. I genuinely felt like I had learned quite a bit after working through the guide, as opposed to mindlessly following steps to acheive a goal.

I wasn't able to apply a recent update, and had to reinstall the software, and some steps had changed, but I was able to figure them out on my own as I kind of understood what I was supposed to be doing. Nonetheless, I wouldn't describe the process as easy. And keeping your cloud maintained will also require some work. So if you want to try it, but don't have the time or patience to go through the set up and maintainence, then take a look for a provider.

As an alternative to other cloud providers, NextCloud is actually really good. There is a huge community making stuff for it. At it's most basic it will back up files to the cloud and sync with any number of devices you want it to, giving you local backups if anything was to go wrong. There's a plethora of compatible software for it, and getting your phone sync'd to it is pretty easy too. I'm currently using it as my Documents folder on two computers, so everything I'm working on is accessible anywhere. I also have my git repositories on it, and have had no issues with those. I'm also using it as the directories for software like Publii CMS and Calibre Library, so my blogs and books are available at whatever computer I'm working at.
